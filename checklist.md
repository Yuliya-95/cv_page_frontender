# QA Portfolio: CV Page Testing Checklist

## 📱 UI & Layout Testing (Size and Responsiveness)
- [ ] 1. Check layout responsiveness on mobile screens (Ensure no horizontal scroll appears).
- [ ] 2. Verify that the video container scales correctly on mobile devices and doesn't cut off.
- [ ] 3. Verify that navigation buttons don't overlap text on different screen sizes.

## 🎛️ Functional Testing (Menu & Buttons)
- [ ] 4. Verify that clicking the "Expand" button smoothly opens the menu.
- [ ] 5. Verify that clicking the "Collapse" button closes the menu.
- [ ] 6. Stress test: Rapidly click the menu button 10 times to check code stability.

## 🎬 Media Testing (Beavers Video)
- [ ] 7. Verify that the video player plays content correctly upon clicking the Play button.
- [ ] 8. Verify that the video player pauses correctly upon clicking the Pause button.
- [ ] 9. Verify full-screen mode works without breaking the page layout.

## ✉️ Contact Information Testing
- [ ]  10. Click on the Phone number to check if it triggers a mobile call application (tel: link).
- [ ] 11. Click on the Email link to check if it opens the default email client (mailto: link).
- [ ] 12. Negative test: Click on contact links while the network is disconnected.
